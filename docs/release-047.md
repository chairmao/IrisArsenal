## 枪口高度与坐标

- 极致驱动、极速火神炮的实际武器/枪口离脚底高度改为原1.5倍。引擎竖直轴是Y，对应用户描述的高度z。
- 脚底基准为每帧最低Foot骨减该原生骨架静止站立Foot高度：男性约0.954692，女性约0.951239。这样不会把脚骨中心误当地面，也不会对世界海拔乘1.5。
- 在真正发射窗口内完成抬高，前后用源时间0.2秒接回原姿态，避免把收枪高举也过度抬高。仅离线右臂/锁骨IK与现有左手握点求解；不伸长骨骼，不修改角色根运动，不在运行时写骨/锁移动。
- 实际武器Prop2继续提供唯一SourcePose；普通武器、源枪体附件、枪口火焰、弹体、光炮和物理起点读取同一变换，不额外给碰撞或特效各加一份高度。
- 从改前备份和当前真实男女骨架反算，发射窗口的高度比例误差小于0.00002；水平枪口、脚底、根轨道和武器朝向保持。脉冲之焰未改高度。

## 三远程入站受击保护

三招各新增`[Move.vulcan/pulse/drive] ImmuneHitReactions=1`，可以改0恢复原生受击反应。只复用已有`Character::_startStumble`钩子，钩子总数仍18。

远程不伪造近战`currentTechnique`，所以新增独立窗口检查：本次远程预约/活动、原生远程状态、同一个私有动画要求身份、有效原生进度和stillPlaying谓词均成立才保护。普通受击不取消本片段；伤害照常先走医疗，保留一次`_getHit(false)`原生记账。死亡/昏迷/倒地/失效/加载、动作结束与纯后效都不延长保护。

这是自身入站反应控制，和向敌人输出伤害的格挡/闪避策略完全分开。三远程依然不会注册额外防御上下文，`_NV_hitByMeleeAttack`桥接及原始HIT_SWORD/HIT_MISSED返回值保持，供用户继续测试。
