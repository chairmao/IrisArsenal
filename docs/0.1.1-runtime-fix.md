## 显示问题的证据边界

原代码创建19层源钻头后没有逐层setMaterialName重绑；Ephnel已验证的材质修复路径恰有此步骤。游戏kenshi.log记录了iris_drill.mesh加载，未见源iris DDS纹理加载。默认DebugDraw=1还叠加了独立胶囊线框。
这证明存在材质绑定核验遗漏和诊断辅助默认开启；仅凭日志仍不能确定用户看到的绿色像素全部来自哪一层。0.1.1先补齐可检验的绑定和before/after日志，关闭默认线框，等待新录像确认，不宣称颜色问题已经实机解决。
