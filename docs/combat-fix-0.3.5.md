# IrisArsenal 0.3.5 八项修正

本轮只修改项目源码、作者工具和package资产。未编译、未部署、未启动游戏，日志轮询仍停止。现有游戏仍为用户编译的0.3.4；035包ready=false，严禁混用旧DLL和新13类FX/5条曲线。

1. 火神炮弹速320→800，2.5倍；脉冲220→440，2倍。单位为游戏距离/游戏秒，继续使用游戏变速和本次原生攻速，不用墙钟。
2. 地震仍是四次真实三维球R36伤害；源六层火焰每层整段最大水平半径36。火焰有源生长/消退曲线，不能解释为每帧填满三维伤害球，垂直视觉也不等同球壳。
3. 本次034运行03:08:22.779、钻天破cast63/event5后反复hit_fraction_out_of_range。旧ResolveJobs在队首失败直接return，所有后续伤害事件可能被挡住。035改为各事件独立轮转，失败保留自身游标，完整批次成功才提交，后续作业照常运行。旧rawFraction未记录，不能编造它是-1或NaN，也不把64条native_hit日志限额当作最后实际伤害时间。
4. 刀/钻这种体积消费者改用官方PhysX accurate胶囊重叠，几何仍是有限线段加球半径，不依赖不需要的TOI。飞弹及墙体仍用真实扫掠：坏比例只有同一shape精确证明出生球已重叠才恢复t=0；其他非法比例、NaN、身份/容量错误仍拒绝整批，没有钳位远处命中或兜底扣血。
5. 钻天破在自己的私有原生动作有效期间免疫普通小/大受击反应。医疗、护甲、原生_getHit(false)受击记账仍执行；死亡、昏迷、既有倒地、镣铐、加载/失效继续原生流程。未增加移动/停止动画锁，不写健康、韧性或共享招式字段。
6. 终结击独立为九层：原Iris蓝白冲击三层先发、原火焰六层尾波，采用真实源网格/贴图/UV/透明/变换曲线，按237～242秒录像节奏适配2.4游戏秒。球伤害仍R60、5倍，不额外加段数。原ESP真正指向ALSExp/ALSshockExp，但本机依赖缺这两文件，EXDrill2蒙皮形态也未完成移植，因此不能称完全还原原终结效果；没有把这些缺口隐瞒为已完成。
7. 已修复实际kenshi.log报告的scene_blend replace不支持：实体明确one zero，四张源透明弧光保留alpha_blend。准备资产流程补上独立钻头材质作者，57条实际混合声明逐条检查。
8. 全力爆发原来每次HitFrame只查当帧/上一帧，很容易错过整条挥刀弧。现按源Collision_Add/Remove的三个有效窗口持续检测：1.338835～1.788817、1.788817～2.655449、2.655449～2.888777秒（与三倍蓄刃后实际身体同一时钟）。ID1是DamageMult0拖尾，没有误算第四刀；每敌人每段最多一次，倍率仍2/2/3，长度90、半径4/4/8不变。只按实际枪口/武器位置查询，不强扭角色去追敌；FCS起手20～100不等于保证移动目标必中。

事件结算改为持续的damage_query_complete / damage_result汇总，区分无物理敌人、原生格挡、原生未命中和拒绝；不再64行之后失去整个后半程结算证据。applied仅表示原生返回命中，不冒称已测真实HP差值。每帧64次场景查询（已有伤害作业预留16次、飞弹独立轮转）、每请求8路径、医疗12次/1ms软预算及256作业/2048医疗请求上限保持；新增持续光刃会增加有效窗口内查询，实际CPU/FPS仍需实机。
