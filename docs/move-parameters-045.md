# IrisArsenal 0.4.5 参数清单与填写表

依据当前项目实际C++、042事件流与运行包FCS逐项核对。此表是当前默认值，**不是伤害实测，也不是已部署状态**。待用户首次编译0.4.5并同步后，下面INI参数以后只需重启游戏即可生效。

## 配置入口与边界

- 项目默认：`distribution/IrisArsenal.ini`；运行包：`package/IrisArsenal/IrisArsenal.ini`。游戏同步后修改 `D:\steam\steamapps\common\Kenshi\mods\IrisArsenal\IrisArsenal.ini`。
- `[Move.<英文名>] Damage1..DamageN`：第1到第N次独立健康事件，0～1000倍；0只取消该次扣血，保留特效。十招共58个倍率（近战31、远程27）。事件次数、时序不通过倍率增减。
- `[MoveWeights] <英文名>=权重`：0禁用；仍保留当前设置。
- 七招近战的 `AttackMin/AttackMax=-1` 表示从实际加载的FCS继承。填写0～10000则仅覆盖本武器的私有技巧副本；必须最小≤最大。单位与FCS的attack distance相同，边界含端点；**不是武器length，也不乘2**。仅控制起手选招，不能保证任意方向/姿势都命中。
- 三招远程起手0～10000继续取FCS，不加入INI距离覆盖：极致驱动的上限还绑定真实柱长/显示长度，避免拆开改坏。
- **仅七招近战** `BypassBlockDodge=1`：已经通过物理命中和敌我筛选的伤害跳过原生格挡/闪避；0保留原生判定。两项走同一个已验证原生入口，未拆成两个未经验证的机制。
- 三招远程不提供额外格挡/闪避开关。**火神炮已按最新指令移除额外防御适配**：不会注册该次TLS防御上下文，不强制将原生结果改为命中。脉冲/光炮保持本轮当前桥接策略。**实现边界**：三招健康入口目前仍是 `_NV_hitByMeleeAttack`，本次未迁到要求真实Harpoon的 `iShotYou`；因此不能把“去除火神额外处理”声称为“已验证原生弩弹结算”。
- 六招特效近战另有独立的 `PreventBlockInterrupt`（防止攻击主动转格挡）和 `ImmuneHitReactions`（免疫普通小僵直与大踉跄）。各为0/1，默认1。无特效三连击/远程不扩展这两项免疫。两开关不代表无敌；正常医疗、死亡、昏迷、已倒地、加载/动作失效等仍退出。
- `DamageEnabled`、`DamageUnconsciousTargets`、`MaxActiveActors`、`RangedActionInterval` 等已有全局配置保留。所有特效伤害仍仅对有效isEnemy且非玩家成员，护甲/部位/医疗原生处理。
- 倍率基数：每次结算时 `stats->getTotalAttackDamageFor(victim)` 的原生总攻击伤害，经 `damage.multiply(倍率)` 后进入一次原生命中/医疗；不是武器面板伤害，也不是动作开始时的武器快照。0倍在医疗前直接跳过。
- 不开放独立的半径、长度、落点、枪口、轴向、持续时间、事件时刻；这些与特效资源/原生片段绑定。动作攻速、特效/弹体时钟继续跟随原生攻速与游戏速度，没有新增倍率干扰。
- 缺项/空值继承默认；非法数、非有限、溢出、超范围或非0/1布尔拒绝启动并在日志定位节/键，修正后重启。新启动日志每招一行有效倍率/开关，再一行实际解析距离，不逐帧读INI。
- 一键更新合并保留游戏中的已有个人数值，只追加缺失节/键。项目模板适合新包默认，个人使用调游戏INI；已有个人键不会被模板强行覆盖。

## 坐标与落点读法

Kenshi世界坐标的 **Y为高度**，X/Z为水平面；角色本地+Z为前方。下面“前20”是起手朝向旋转后的角色局部向量，不是世界Z固定加20。

实际枪口 `M = W × (1.807138657, 0, 8.534358047) + origin`，W来自源对齐后的实际武器姿态。W和角色相对变换随每一帧变化，所以不能给武器轨迹/枪口/两翼中心捏造一个恒定的“角色前方若干米”。两翼中心从同一源翼片采样流插值后经W转换；它与球爆中心及蓝/火后效共用同一位置。

真实武器8胶囊的源轴向范围约-8.443～8.325、径向半径约1.659～4.508；每段还具有实际横向偏心，并按实际武器比例变换。不是一个可随意改半径的球。胶囊/球/柱均在三维PhysX形体上查询，同一敌人同一事件去重；不同事件可再次伤害。
