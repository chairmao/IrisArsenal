# 性能优化复盘

## 先规定可比的成本

不能用两轮不同输入的混合均值认定算法提升。至少同时列：活动游戏秒、实际施放/事件、弹体数、查询API调用/原始形体/去重角色、入队/结算/拒绝、断肢开关、日志/特效开关、DLL及配置哈希。不同技能每弹命中人数差很大，应看每弹总查询、每API、每候选、每唯一可伤角色及医疗分开成本；不能仅说火神弹多所以更慢。

墙钟包含抢占/嵌套/其他mod，不直接等于纯CPU；inclusive父子不可重复相加，抽样样本不能当全量分布。摘要混入长暂停/空闲会稀释活动负载。先扣一次性visual_create（仅在所用报告明确如此）再列持续开销，不能在不同报告换分母制造收益。日志IO可关但仍应说明是否计入；FPS和GPU需要独立测量。

## 已保留的方向及依据

| 阶段 | 实际工作量变化 | 安全/性能边界 |
|---|---|---|
| 075多持有者独立起手 | 取消其他角色active/reserved占用对本角色的全局起手串行 | 不省每次必要工作，但恢复多人功能；同角色busy/pending仍有 |
| 076普通Hook预筛 | 非本武器/非私有技巧直接原转发，减少普通角色进入共用锁 | 用真实武器身份，不以玩家/固定类别粗筛；不确认走原慢路 |
| 080/087容器与身份 | 同窗口身份哈希完整比较、Job交换/列表splice、减少名单/路径深拷贝/临时分配 | 不跨帧缓存引擎裸指针；保留异常与动态容量 |
| 083医疗门 | 已完成碰撞的Hurt不再等全局物理消息清空 | 保留线程/世界/暂停与逐笔安全，不等同于放开PhysX |
| 086～090查询组织 | 同安全窗口批量/空间空区证据、已成功前缀复用、有限相同查询复用、弹体轮转 | 无额外常驻高压索引；移动弹体保留首次接触和未完成区间 |
| 091～093观测与省写 | 同次源采样/附件数量标量、真实输出相同比特的参数组才省setter | 非跨帧人物缓存；保留节点变换、custom1/custom9与必要插值；未证总帧提升 |
| 097原生AABB/扇形裁剪 | 静态胶囊交原生overlapCapsuleShapes(false)，光刃交原生cullShapes | 用户接受额外候选；不声称SDK显式保证任何输入更快 |
| 098钻头球 | 11段由源钻头/外环紧包围球替代每段旧复合扫掠 | 事件时刻、中心随钻头移动；不把11段合成一次 |
| 099/后续配额调整 | 2.5/32逐步调到当前20/128，关闭额外追赶 | 服务吞吐调优，不是算法少工作；单次原生仍不可抢占 |
| 102固定弹速/射程 | 火神1500、脉冲1000、射程5000，飞行脱离攻速 | 是明确用户功能参数变更，可减少飞空驻留但不等于所有场景省查询 |

## 撤回、收益不足与不能算优化完成的内容

| 方案 | 项目结论 | 以后如何处理 |
|---|---|---|
| 094/095保守近似全链证明 | AABB局部包含/少调用不满足当时1.2体积+全链性能证明，已有配置空间/移动爆心反例 | 定义实际有效区域与目标变换，列rho与成本；不得把日志当数学/API保证 |
| 096真实形体验证/复杂证书或缓存实验 | 用户反馈更慢并要求回退；不能把更精确又重算说成近似性能优化完成 | 不带入新模板默认；对比095和两次094时须归一输入 |
| 100查询精细安全门 | 几乎没有可观测收益，因为真实创建/销毁消息仍非空；无已证性能损失而保留 | 注释/INI应保留测量结论，不继续堆新安全许可机制 |
| 101尾部补处理/carry | 提前处理部分请求，但整体群伤服务长尾改善有限，用户要求回100撤回 | 当前不恢复。后来的102弹速/分段时钟是另一个功能，不能按数字混为一谈 |
| 在渲染帧末尾新增医疗/强清消息 | 没有原生阶段/重入/生命周期证据 | 不实施；不能仅凭physics.isRunning=false取得所有调用许可 |
| 全局按事件串行屏障 | 用户否决，会把查询流水推迟到医疗队头 | 不实施，保留已入队FIFO |
| 原生伤口/截肢语义改写 | 断肢开关对照支持amputate子树是原生大头，用户决定不改 | 深层探针只观察；不为省时合并独立医疗或跳掉肢体处理 |
| 冷却/排队更多冒充均摊 | 可降低单帧峰值但扩大端到端延迟 | 必须同时验收平均/P95/P99/最大等待，不靠积压制造“优化” |

## 新项目每次优化的准入条件

1. 定位可重复的具体多余工作与主耗时层级，不从全局FPS直觉跳到某个函数。
2. 写清前后调用链、读写对象、线程/重入/失效和输出等价条件，明确普通负载新增成本。
3. 算构造/维护/查询/过滤/去重/分发全部成本。若允许近似，实际有效体积比rho应计入新增碰撞请求rho*N，额外医疗单列；不能用名义几何代替目标变换后的区域。
4. 按同输入离线命中/逐段次数/顺序检查，再用户新DLL同压力AB；正常模式不做额外精确影子查询。
5. 收益达不到预设阈值就不合入/撤回；若保留需写理由/开关/成本，不累计难维护的小收益分支。不能因没有新方案就宣布引擎已数学最优。
