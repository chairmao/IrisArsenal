# 新专属武器项目模板

目标：将IrisArsenal证明过的结构和验证方法复用到另外1～2把武器；不复制尚未证明的假设。先填本表和JSON，再按阶段落地代码。当前Iris源码快照可作为参考实现，不能全局字符串替换后直接发布。

## A. 项目基本表（复制后填写）

| 字段 | 新项目填写 | Iris示例/约束 |
|---|---|---|
| 项目与mod目录名 | TODO | 所有资产、材质、动画、技巧、日志及合同前缀唯一 |
| 武器stringID / 允许装备槽 | TODO | 用真实GameData身份，不按显示名/玩家小队筛选 |
| 原生武器类别 | TODO | 从FCS读取；原生持械资格与演出双手/单手要求分开 |
| 源作品/许可/原作者 | TODO | 本地持有不等于可再分发 |
| 游戏EXE/SDK/RE_Kenshi/PhysX身份 | TODO | 哈希、API族、导出/ABI逐项核对 |
| 原生回退 | TODO | 武术/趴地/不适用/私选失败保留原生结果 |

| 实现范围/明确不做项 | TODO | 先写用户批准的动作、碰撞、防御、时钟 |

## B. 建议的文件职责模板

```text
NewWeapon/
  NewWeapon.sln / .vcxproj / .rc        # v100/x64目标，身份一致
  PluginEntry.cpp                     # 生命周期、成员地址Hook、主线程阶段
  Combat.cpp/.h                       # 私有技巧/Actor/Emit/Job/Hurt/锁外Flush
  RangedAdapter.cpp/.h                 # 仅有远程需求时
  Diagnostics.cpp/.h                  # 可关闭日志和纯值统计
  native/                             # 已确认的SDK查询、身份、配置解析契约
  distribution/NewWeapon.ini          # 默认值、单位、父开关、重启语义
  package/NewWeapon/                  # DLL/FCS/RE_Kenshi.json/assets/清单
  compatibility/                     # 独立种族补丁，不混入主mod
  tools/                              # 离线作者、专项非编译验证、组包、部署分开
  docs/source-provenance/              # 每招源绑定/许可/哈希/采样
  docs/specs/                         # 本模板与明确招式规格
```

是职责建议，不要求新建大量空文件。只含原生无特效近战时优先原FCS流程，不复制Iris所有Hook和队列。只有独立空间/后效/弹体确实需要时才建相应独立消费者。

## C. 每招必须填写

名字/视频起止/源HKX与clip/根运动与WEAPON轨道/男女绑定；动画基准长度与速率映射；每段健康事件和单段有效窗口；起手距离/权重；形体与坐标变换；敌我/主动目标/昏迷规则；格挡闪避/主动格挡切换/僵直三个独立策略；源特效绑定图；范围量测；未发/已发中断行为；暂停/读档清理；用户确认的例外。

动作类别先选：原生纯武器、实体附加刀刃、固定位置AOE、移动弹体+爆炸、即时光柱、持续离散伤害。一个招式可组合，不能据颜色/可见武器数推伤害段数。窗口伤害要定义“每时刻均覆盖”还是“事件采样”；慢扫必须按源角速度时序覆盖，不提前查全圈。

使用[招式规格模板.json](招式规格模板.json)。数字保留null/TODO直至有证据，禁止把Iris的R120、双臂门、材质曝光、20ms/128当新项目通用真理。

## D. 最小闭环推进顺序

| 阶段 | 必须交付 | 通过后才能做下一步 |
|---|---|---|
| 0 证据 | 源片段/动作事件/绑定链/许可/游戏版本 | 无关键缺口或明确记录未知 |
| 1 原生能力 | 一招无新增伤害动作、正确握点/根运动/男女骨架 | 原生回退、家具、义肢/趴地和装备正确 |
| 2 单段几何 | 实际SDK命中、完整稳定身份/关系过滤 | 同段去重、地形/角色拆分、直接接触结果正确 |
| 3 原生受击 | 锁外一次原生受击/原经验，不伪造HP | 护甲/部位/防御/昏迷/死亡语义核对 |
| 4 源特效 | 源材质/轨道/粒子时间与范围 | CPU动态+实机对照，不仅静态截图 |
| 5 多段/远程 | 各事件独立、已发后效独立寿命、原生远程许可 | 多人同时释放、目标运动/地形/取消/暂停 |
| 6 压力/优化 | 全量阶段与安全间隔、同输入AB | 达成写明阈值/等价边界，普通负载不倒退 |
| 7 发布/封存 | 新DLL、资源/配置/FCS/合同哈希同包、独立补丁、恢复演练 | 原始内部版本保留，测试与发布日志配置分别留档 |

## E. 必须保留的不变量

1. 默认一个原生目标只转发一次；同段同身份一次伤害，不同段不合并。
2. 不给普通角色加额外全局锁/查询；按实际专用武器早筛，不缓存跨帧引擎裸指针。
3. 主线程/世界/线程忙与消息生命周期的许可来自原生调用链和SDK；医疗许可与查询许可独立证明。
4. 当前已发事实进入稳定值型队列；医疗调用锁外、每笔重新验证，不在后台线程调用原生医疗或PhysX。
5. 时钟统一有单位，暂停不推进游戏秒；动画结束不截断已释放效果，读档统一失效。
6. 范围、时序与视觉是一项跨层合同；只改其中一层不能称完成。
7. 日志默认可关闭，关闭时不做新增计时/扫描/字符串；安装型探针关闭生效需重新启动。
8. 只做用户批准改动；不得把皮肤、种族补丁、发布标签或新资格门擅自混进功能修复。

## F. 新项目必跑矩阵

- 正常双臂、伤臂、缺臂、摧毁、正常义肢、伤义肢、单/双腿伤、站姿/趴地、不同FCS类别；原生选武术/NULL/混合技巧分别验证。
- 装备/收起/换原生武器/勾远程/防御/坚守、研究/耕作、不同原生与第三方种族。
- 1/3/8/9/16/更多持有者，玩家和敌人、目标死亡/昏迷/主动中立/盟友、完整hand同index不同serial。
- 相切、初始重叠、墙前后/坡地/起点墙内、低枪口、移动目标、空射到期、直接接触与爆炸去重。
- 慢/快攻速、低帧率、跨事件/片尾、循环回退、暂停/倍速、世界重置/读档/场景变化；已发后效正确完成。
- 日志全开/明细关/全关，普通/高压/断肢开关对照，失败/容量/哈希冲突/身份异常不整批重算。

每项写证据类型：源码AST、纯值回放、真实引擎、用户实机录像或尚未验证。不能把第一种填成第四种。
