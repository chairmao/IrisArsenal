# 碰撞、伤害、时钟与生命周期

## 当前查询映射

| 命中体 | 当前实际入口 | 时序与结果 |
|---|---|---|
| 静态球/爆炸 | OverlapSphere → overlapSphereShapes；approximate由EnableConservativeDamageQueries或boundsOnly决定 | true精确标志是!approximate；当前配置下对角色AABB，保留球几何 |
| 钻头前11段 | OverlapSphere，boundsOnly明确开启 | 每事件重新定位当前钻头球，11段分别去重 |
| 实体武器代理胶囊 | OverlapCapsule → overlapCapsuleShapes(...,false) | 目标为SDK AABB候选；严格零长度才转换overlapSphereShapes，短而非零不吞掉 |
| 胶囊复合 | OverlapCapsules逐条调用上述原生接口 | 每条结果/事件独立，成功前缀可消费，失败不整批重查；不是一次神奇扇形接口 |
| 光刃厚扇形 | Swing/TraceBladeWindows → OverlapSector → cullShapes平面裁剪 | SDK允许额外候选，用户接受去重后直接使用，不补自写窄相；单片≤90° |
| 移动火神/脉冲 | ProjectileAll/SweepAll、连续移动球，另RayBlocker | 保留首次接触fraction、最近可伤目标与环境比较；不能改无半径角色射线 |
| 极致驱动 | CylinderAll → 原生候选与有限平端柱/AABB判定；另中心地形射线 | 不是有时序先后的移动胶囊；柱体原长/实际环境裁短长度共用于绘制 |

静态空间查询可以忽略TOI，移动弹体不能：保守膨胀导致更早撞到别的人，爆心前移后可能漏掉旧爆心附近受害人，所以“局部E⊆A”不推出整招受害名单包含。不能为补漏无界扩大爆炸，也不能把球直接变成盒就宣称性能/体积界成立。096实验已撤回，当前097原生AABB/裁剪取舍由后续用户明确批准，不继承未完成的1.2/1.5倍全链证明称号。

角色形体回调是引擎查询结果，不代表每个形体一次伤害。Collector/IdentityIndex按完整稳定键去重，哈希冲突必须继续比较全部身份；动态结果容器按需增长，64项回调buffer是分块接收，不是总结果最多64。旧512候选/1024检查/256结果限制与额外旧查询默认对照已按后续方案变更，不能从早期文档抄回。身份/几何异常按项跳过、可关闭诊断；临时场景忙/SDK失败不同于坏形体，需要保留未完成任务，不整批重算成功部分。

## 地形分组与首次接触

原生弩弹飞行用0x087FDE47，而开火前trace/trace2有不同组，不能混为一条“视线射线”。本项目环境RayBlocker使用caller_groups & 0x087FDE47，跳角色后继续找最近真实环境形体；角色仍单独按半径扫掠。建筑/触发体不能全跳，合法t=0起点位于墙体仍应阻挡。相同fraction环境优先；非伤害资格角色在远程接触列表中过滤透明。证据：docs/native-terrain077.md及原生GunClass/Harpoon/Tracer取证。

射程到期不是撞击。projectile_expire contact=0不爆炸、不造伤害；直接撞人时将稳定目标身份种入同一爆炸Job，防止排队后相切/移动导致第二次球查询找不到它。同段去重，只原生结算一次；种子仍重验资格，不是无条件补血伤害。

## 伤害资格和去重层次

DamagePolicyReason：指针/自身/有效性、死亡安全门 → isAlly(v,false)跳过 → 真昏迷跳过 → isEnemy(v,true)允许 → 否则只有对应近战/远程当前主动目标放行。中立关系可在主动攻击后改变，不是一个永远与敌人互斥的标签；玩家可被敌人使用本武器正常伤害。碰撞筛选和医疗前再次核对是不同时间点，后者处理队列中身份/关系变化，不是重复几何查询。

Shape级身份去重 → 同Job名单 → 同cast/event去重；下一独立事件仍可伤害同一人。全力前两刀跨多个扇形片共享“这一刀”名单，第二刀独立；钻头11段、20发火神和4段光柱不能合成一次。原生护甲/部位/经验按每笔原受击，不为省性能汇总医疗金额。

## 两种安全门不能混用

查询需要有效NxScene/SDK、物理/AI处于允许阶段及创建/销毁/地形等队列满足条件。100精细门只在旧门false时查看实际主/后台消息及SDK可写状态，没有跨帧许可，不强制执行消息；已测几乎无收益但也无已证性能损失而保留。

医疗已经只有稳定身份和值型伤害请求，不需每次等待全局physics消息队列为空；083解除该额外门，仍逐笔检查世界/读档/暂停、physics线程、AI、身份与资格。原生受击可重入其他mod，因此出锁调用；回来后的下一笔重新检查。不能把“医疗不必队列清空”照搬成“所有PhysX都可忽略消息”。

## 调度、容量及等待的准确含义

当前普通医疗20ms软预算、128次原生调用、256笔检查上限；FIFO请求先出队，预算在每笔之间检查，单次不可抢占。EnableDamageBacklogCatchup=0，其他追赶数值保留但不生效。INI直接读数，仅类型/有限值/格式等结构检查，不重新偷偷加入10ms之类业务硬钳制。

64次场景查询预算在弹体/Job之间共享，已有Job保留一部分服务机会；轮转保留未查询弹体的pending游戏秒，不挪动/不丢轨迹，失败不消费事件。仍有Job/后效闲池等运行保护，它们不是正式8名持有者限制，也不是主动弹体数量上限（090已解除）。所有实际容量条件见当前源码；模板不应一口气删除全部数值。

查询任务生命周期/队列等待/安全门等待/暂停时间/SDK实际运行耗时必须分开。延期不会让CPU空转；主线程继续处理游戏其他工作。提高医疗预算只能改善获准窗口内吞吐，不能消除查询未能执行的1秒等待。用户已否决“前一事件所有医疗完成才查询后一事件”的全局屏障；当前保持查询/医疗流水与已入队FIFO，不承诺不同任务完成顺序严格按事件时间排序。

## 时钟与清理

动作：原生速率×导出长度归一化；已发Shot：独立游戏秒×固定速度；独立翻滚/钻天破/全力/远程命中爆炸：游戏秒；连续配套地震/电脉等：保留动作时钟。暂停不推进游戏时钟。源动画以结束时间决定人物，已发弹体/爆炸拥有独立寿命；人物End只隐藏附件、归还远程忙状态，不删已发Job/Hurt/Shot/Residue。

跨帧持有完整hand与自有值、Visual/Slot，不借人物/NxShape/NxActor裸地址。Clear在世界/场景失效时递增epoch并清Actor、Shot、Residue、池、Job、Hurt、去重表与时钟；alive决定是否还能接触有效Ogre场景。旧HybridGun可能仍被原生消息引用，保留到队列清空后标准析构；不能为注册更多角色提前delete。

104片尾审计只在End清状态前读现有快照：time_known=0时只记剩余，不断言漏发；due_pending不自动补发；kind5标记与blade_sample_gap单列。关闭EnableActionEndLogging后直接返回；已发但还没医疗的事件不算漏Emit。证据：`IrisCombat.cpp:461`（AuditActionEnd）、`IrisCombat.cpp:487`（End）、`IrisCombat.cpp:491`（Clear）。
