## 查明的资源链

全力爆发：HKX `PIE.$FullBust_End` → Iris.ini → Skyrim.esm SPEL `0003F9ED` → MGEF `000562EB` → PROJ `000647BE` → `Magic/VoiceFlameWaveProject03.nif`。主文件含六片有曲率/厚度的火浪网格与七个 `BSValueNode ID64`。ID64由原版 ADDN `000647BC` 解析为 `MPS/MPSFireWaveFlames.nif`。此前039用通用FireballExp代替，并把火团重新摆在八象限，不是这条实源链，已移除该路径。

火神炮：`IrisShoot1` → Iris ESP PROJ `0400085D` 的 NAM1 → `RimMagic/SW_MagMuzzle.nif` → `BSValueNode ID9` → 原版 ADDN `0002B95B` → `MPS/MPSFireBoltImpact01.nif`。这个枪口NIF本身没有网格；只搬它会漏掉真正的五层火焰、火星、余烬和闪光。

在提供的Elden Rim Base目录中，上述Form没有被四个依赖ESP覆盖，也没有同名松散NIF覆盖。源块字段按niftools官方nif.xml核对，摘要见证据JSON；不是按文件名猜测效果。
