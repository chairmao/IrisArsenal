1. **近远程统一资格**：先保留指针有效性、自身/死亡安全检查，然后按用户指定的原生四项顺序：isAlly(v,false)排除；真正昏迷排除；isEnemy(v,true)允许；否则仅当前主动目标允许。近战和远程分别读取自身CombatClass/RangedCombatClass当前目标，不借错战斗对象。旁观中立不会受波及，主动中立目标可伤；盟友和真昏迷优先排除。原DamageUnconsciousTargets选项退役，不再推翻此规则。特殊奴隶分支未追加，本次按用户明确列出的四项。
2. **不能受伤的角色透明**：远程球扫掠先筛掉不具资格角色，再按fraction找最近可伤目标，与环境射线比较；同距仍墙先。光炮柱体名单也用同一资格。最终医疗再次核对；延迟期间成为盟友、真昏迷或不再是主动中立目标时会拒绝并留原因。原生起手的友军/视线门保留，因此物理透明不等于绕过原生开火许可。
3. **直接命中不再依赖二次重找**：旧AdvanceEffects已经得到直接接触稳定身份，却只把位置交给Blast；后续爆炸球可能因相切/移动/排队未返回该目标。现在将成功扫掠的稳定hand种入同一Job的set，与范围名单合并、同段一次。仍经过资格及原生伤害链，不额外调用医疗、不扩大球体、不跨段合并。这个缺口由代码确认；没有把每一例旧录像无伤都断言为此原因。
4. **有效弹速匹配原生预判**：旧私有Gun固定shotSpeed=320，而实际火神800、脉冲440还乘发射时攻速。现在安全窗口先按FCS/INI权重选定本轮动作，等待原生许可期间保持选择；Publish实际弹速=基础速度×动作速率，再用原生getAimPos刷新。每次发射仍从当帧实际附件炮口取得同源瞄准快照；光炮即时脉冲使用原生同源Spine1/Spine2身体点，无慢弹体提前量。原生仍自行更新其瞄准/许可缓存；本插件不重复调用takeTheShotCheck或Tracer。身体点/炮口发布是既有主线程安全窗口的快照，不能保证跨原生异步阶段零时间差。
5. **射程不再在瞄准点后40结束**：旧弹体range=max(aimDistance+40,120)，并把到期也当作爆炸。现在三远程实际飞行上限使用该招私有FCS initialDistance（当前10000）。没有接触而飞到射程会自然回收，日志projectile_expire明确contact=0、damage_job=0；真正碰撞才Blast。
6. **完整诊断**：取消首次N次永久静默门、慢调用/慢帧和队列压力的时间节流门；仍按配置开关、数值变化、阈值和周期摘要控制。包含逐发瞄准来源/实际弹速/最大飞行距离、接触身份/墙体、直接身份种子、入队、拒绝原因和原生返回值。新增护甲前提交伤害总量在原生入口前快照，不能冒称实扣HP。磁盘失败保留64KiB内存缓冲和dropped_log_bytes，以防诊断故障无限占内存；这不是日志文件行数上限。
