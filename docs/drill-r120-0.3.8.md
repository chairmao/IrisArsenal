# 钻天破终结 0.3.8：两翼中心直接球形爆炸

本轮依据用户录像 `3CCA45~1.MP4` 及后续明确要求修改：终结没有弹道，直接在张开两翼的对称中心引爆；伤害球半径120；蓝色电离和随后火焰爆炸需覆盖该范围。沿用本任务完整代码/资产授权。

## 最终行为

- 原HKX的终结触发事件到达时，读取当帧两翼中心，乘同一真实武器矩阵并加浮动世界原点，保存一次世界坐标。后续角色或目标移动不拖动球心。
- 中心由原EXDrill2每侧五个形状的整体几何包围中心取中点得到，离线导出115采样；与可见翼片同一源时钟、同一单位、同一姿态。运行时只插值，不扫描高模顶点。
- 该事件直接进入既有 `Blast`：视觉后效与单个 `Path(p,p,120,true)` 共用p。没有Shot、飞行速度、弹道或碰地后再引爆。源事件内部保留历史枚举编号4，仅用于序列化兼容，不代表038消费者仍发炮弹。
- 一次5倍武器伤害，原enemy/玩家保护、昏迷选项、护甲与队列预算保留。三维球形查询继续走原生PhysX OverlapSphere，不是地面圆。

## 可见性处理

旧终结除以保守包围球半径，会把可见部分进一步缩小；038将“单位显示半径=真实伤害半径”和裁剪边界分开。原ALS电环按实际输出的可见采样校准到R120；恢复源蓝闪增益，仍为0～0.52游戏秒，火焰从0.56秒开始。

原151个有限源粒子保留，新增蓝/火各49个有界三维覆盖粒子，使用已存在的源羽化贴图和火焰动态图集，增加两个材质子层。核心、内层、外层均有独立空间位置，火相有径向扩散与升腾；不借地震贴地喷流、不绘制不透明球壳、不新增伤害/物理体。柔边可超出伤害边界，不会把实际伤害半径扩大。

覆盖层位置布局是为本次R120要求做的适配，不宣称与Skyrim全部NiPSys仿真逐点一致。高强度爆炸在实际游戏中是否足够清楚、是否过曝、密集场景的GPU填充成本，仍需新DLL实机复测。
