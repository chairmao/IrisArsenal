# IrisArsenal 0.3.6 特效与伤害资格修正

本轮源码/资产静态检查通过，未编译、未部署、未运行游戏测试。实际用户已编译部署并运行过035，最新日志为04:01:54启动、04:17:18附近收尾的PID39872；不能再沿用旧文“实际游戏034”。当前游戏文件保持035。本轮未启动/终止游戏、未恢复轮询、未修改存档或其他mod。

1. 钻天破终结“橡皮泥”：找到035错误导入的GeoSphere01:0。本源BSLightingShaderProperty有Refraction位0x8000和强度0.6，035却用one zero将它作为不透明实体。036明确不渲染该折射辅助壳，保留2层真实透明气浪；6层火焰改用独立尺度和上升高度，不再被巨球包围盒压成小火苗。无遮罩Glow改用源库GlowSlightFlash羽化遮罩。终结仍为R60球、5倍、一次爆炸；目前8层透明适配，原ALSExp/ALSshockExp仍缺失，不能称原版完整移植。Refraction位定义见[NifTools原始格式说明](https://www.niftools.org/nifxml/SkyrimShaderPropertyFlags1.html)。
2. 钻天破、全力爆发、地震与原来已有的火神，在真实物理命中且资格成立后使用同一单次TLS防御门。身份同时匹配combat、Damages地址和攻击者；格挡/闪避结果不能挡住该次伤害。护甲、部位、医疗、经验仍原生，只调用一次受伤入口。其他四招保持原有防御规则，不扩大为全角色被动破防。原生在门前早退时仅记诊断，不重放医疗，也不因此永久关闭整个插件。
3. 所有自有伤害在接触收集和最终扣血前各核一次isEnemy，并始终保护玩家成员；中立/友军不能受伤。新增INI `[IrisArsenal] DamageUnconsciousTargets=1`，默认允许昏迷敌人；改为0后两处都排除原生medical.isUnconcious()成立者。趴地但清醒、断腿爬行不等于昏迷；死者仍排除。配置只影响伤害资格，不篡改原生选敌/碰撞组，启动读取、修改后重启生效。
4. 火焰翻滚独立使用原explosionwarm0六层、4秒完整颜色/UV/透明/变换曲线，以及源IrisExplosion时刻的小型点火前导。原来的通用静态1.1秒小火苗不再用于本招。点火/尾焰只装饰，不增加原来两段健康事件；主爆炸仍跟随炮弹真实落点、半径24与2倍保持。
5. 地震和翻滚维持水平半径36/24，竖向可视独立校准：主体LowerFlame顶部约为半径0.72倍，分别25.92/17.28；中层0.36倍、气浪0.16倍、辉光0.025倍。保持原纹理流动和源扩散，不将整片地面平移起来，不更改伤害球中心/半径。装饰火焰边缘不是物理球壳，不能把每个火焰像素理解为伤害边界。
6. 源Backfire提示逐个落入effect_cues.csv，各次尾焰从自己的触发点开始读mSprayShort，避免动作后段取到已结束帧。火神的附加枪体从真实IrisAnim出现，到动作收尾清理；全力爆发补回charge3真实5层能量流，循环1.3333秒，跟同一枪口轴/90长光刃。源起手OffAll只清理此前出生的附件，不会把后来charge3永久屏蔽。新增附件都有结束隐藏、演员销毁与换场景清理。
7. 锤枪FCS skill category改为SKILL_HEAVY=3，animation override仍ATTACK_NULL=21（使用本类原生动作）；八个私有技巧和旧无伤害原型记录同步heavy weapons=true、polearm=false。技能按本武器ID私有选择，公共chance=0/disabled，其他重武器不会获得这八招。伤害倍率、FCS距离、INI权重、弹速800/440、间隔1均保留。

本次实际资源为15类特效（加钻头共16类预热资源）、7条分层曲线；总查询/医疗预算、命中去重与资源池界限不改。没有新增贴图文件，现有源库纹理共享；更精细的几何/延长火焰绘制仍可能增加局部GPU工作，未测量实际FPS或显存收益。
