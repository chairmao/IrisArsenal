## 已接入的共用机制

1. 两套具名人形骨架共16份动作；遵循源lock_translation参考位移，未锁COM/root保留跃起。身体、道具、根移动、事件共用变速映射；不运行时强写骨骼或角色坐标，不装移动锁。
2. 真实装备附件统一驱动枪口、部件、可视及代理。正常武器和钻头从实体顶点拟合8段保守代理，不是三角网格刚体。除火神弹外，炮弹碰撞半径与大爆炸半径分开，避免出生撞地；弹体按实际网格中心/包围球校准。
3. 物理/AI静止且创建/销毁队列清空才查询。正式PhysX2.8.4.6接口独立TU，核验SDK/scene同实例；爆炸用accurateCollision=true球形重叠，覆盖三维空间。回调只复制值，不缓存NxShape/Actor，不替换全局contact。
4. 每安全帧64条物理路径，预算不足续查；坏批次不消费，重试当前路径，不永久停用演员/世界。新球形接口尚未经实机，不以旧closest推进近似冒充完整AOE回退。
5. 医疗在插件锁外，每帧最多12次/1ms软预算；每事件/受害者独立去重，不合并段数。接触和医疗前两次enemy检查，保护玩家角色。护甲/部位/反应走原生，不直接写健康。
6. 已发弹/爆炸独立寿命，动作收尾后仍继续；未发事件随动作结束。游戏速度、原生攻速与后效共用时钟，暂停冻结；读档/世界/渲染关闭清理，加载秒不累计成恢复后的飞弹跳跃。
7. 源网格、法线、RGBA、纹理、梯度与UV流速入包。钻头沿用上一轮金属；beam五层源能量管已导出。刀光来自最多16点真实武器历史，160ms渐隐，不加伤害；Iris源尾焰单独显示。
8. 9类资源分帧预热、有界复用。投射物/尾效池96、飞弹64、查询事件256、待医疗2048、候选8；池满保留事件游标。日志不截断总行数，重复失败/明细首N次；没有恢复任何轮询。CPU时间不能证明FPS。
